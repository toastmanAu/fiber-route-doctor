# fnn v0.9.0-rc7 Retarget Implementation Plan (Sub-project A)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Update the local Fiber node to v0.9.0-rc7 (clean data reset) and confirm the existing fiber-route-doctor toolkit still works against it, fixing any residual wire-format drift.

**Architecture:** This is a migration + verification job, not a greenfield feature. The existing `Rpc*` types were written against ~v0.8.0 source and already use the modern `pubkey`/`addresses[]` names, so the large 0.7.1→0.8.0 rename is already handled. Work proceeds: (1) swap the binary + clean-reset the store, (2) diff our types against the real v0.9.0-rc7 source and fix confirmed drift, (3) re-validate live via the existing `smoke:*` harness once the gossip graph re-syncs, (4) refresh fixtures/demo snapshot to 0.9 shapes. Fixes in Tasks 2–4 are conditional on live observation; each candidate has an exact check and an exact remediation.

**Tech Stack:** TypeScript ESM monorepo (npm workspaces), Vitest, tsx; fnn v0.9.0-rc7 (`nervosnetwork/fiber`); systemd user service `fiber-dt.service`.

## Global Constraints

- **Target binary:** `fnn_v0.9.0-rc7-x86_64-linux-portable.tar.gz` from `nervosnetwork/fiber` release `v0.9.0-rc7`; installed at `~/.fiber-dt/bin/fnn`.
- **Clean reset, not `fnn-migrate`:** wipe only `~/.fiber-dt/fiber/store/`. PRESERVE `~/.fiber-dt/biscuit_private_key`, `~/.fiber-dt/biscuit_public_key`, `~/.fiber-dt/data/config.yml`, `~/.fiber-dt/ckb/`, and `~/.fiber-dt/fiber/sk` (node P2P identity — keeping it is harmless and avoids needless churn).
- **Node endpoint:** `http://127.0.0.1:8231`; `rpc.cors_enabled: true` must remain in `config.yml`.
- **Secrets:** NEVER print biscuit tokens, private keys, or passphrases. All node calls mint a readonly token from `~/.fiber-dt/biscuit_private_key` and use it **within the same process**, printing only structural/derived output (counts, keys, booleans).
- **No regression:** `npm test` (currently 244 passing) and `npm run typecheck` (4 tsconfigs) must end green. All six `smoke:*` scripts must pass against the 0.9 node (the `list_channels`/`list_peers` paths are source-verified only, since the node has 0 local channels/peers until Sub-project C).
- **Field-name source of truth:** `crates/fiber-json-types/src/{info,graph,channel,peer}.rs` at tag `v0.9.0-rc7`.
- **Gossip re-sync:** the clean reset wipes the synced testnet graph; the node must re-sync from bootnodes before graph-dependent validation (Diagnose/Map/demo snapshot). Poll before validating.
